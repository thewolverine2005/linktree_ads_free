# BioStack - Free & Ad-Free LinkTree Alternative

A clean, modern, ad-free Link-in-Bio static website built with pure **HTML5**, **CSS3**, and **Vanilla JavaScript**. Designed with ultra-clear typography, high contrast text, multiple themes, and zero bloated frameworks or AI-style slop.

---

## 🚀 Features

- ⚡ **100% Static & Lightweight**: Instant page load times, no build steps, no Node.js build process required.
- 🎨 **Built-in Theme Engine**: Toggle between 5 custom human-crafted themes:
  - **Midnight Dark** (Default)
  - **Minimal Light**
  - **Cyber Neon**
  - **Sunset Glow**
  - **Emerald Forest**
- ✏️ **Live In-Browser Customizer**: Click "Customize Page" to edit profile name, handle, bio, avatar URL, links, and status banner in real-time.
- 💾 **LocalStorage Sync & JSON Export**: Save edits right in your browser or export your config JSON anytime.
- 🔍 **Instant Search & Filter**: Filter link cards dynamically as you type.
- 📱 **QR Code Generator**: Integrated QR Code modal to easily share your page link with smartphone cameras.
- ☕ **Support / Tip Jar Modal**: Dedicated modal for PayPal, Buy Me a Coffee, and crypto wallet addresses with 1-click copy.
- 🎵 **Audio Preview Widget**: Embedded music/podcast preview player card.
- 📩 **Newsletter Subscription Box**: Built-in newsletter signup section.
- 👁️ **Page View Counter**: Tracks views locally without intrusive third-party ad trackers.

---

## 🛠️ How to Use

1. **Open directly in browser**:
   Simply double click `index.html` or open it in any web browser.

2. **Customize Your Page**:
   - Click the **"Customize Page"** button in the top right.
   - Change your profile name, bio, social media handles, and link cards.
   - Select your favorite theme.
   - Click **"Export Config JSON"** to back up your setup.

3. **Deployment Options (Free)**:
   - **GitHub Pages**: Upload these 3 files (`index.html`, `styles.css`, `script.js`) to a GitHub repository and enable GitHub Pages under settings.
   - **Netlify / Vercel / Cloudflare Pages**: Drag and drop the folder directly into Netlify Drop or Cloudflare Pages for instant deployment.
